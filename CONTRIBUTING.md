# Mitwirken

Vorschläge, Fixes, neue Prompts oder Config-Verbesserungen — gerne.

## So geht's

1. **Kleine Fixes** (Tippfehler, Variablen-Defaults, README-Klarstellungen):
   Pull Request direkt gegen `main`.
2. **Neue Prompts** unter `prompts/`:
   - Eine Markdown-Datei pro Prompt
   - Struktur: Titel · Aufgabe · System-Prompt im Code-Block
   - Deutsche Sprache, keine sensiblen Echtdaten in Beispielen
3. **Größere Änderungen** (neue Compose-Overlays, zusätzliche Services):
   Erst Issue öffnen und abstimmen.

## Lizenz der Beiträge

Mit dem Einreichen eines Pull Requests stimmst du zu, dass dein Beitrag
unter der [MIT-Lizenz](LICENSE) dieses Projekts steht (*inbound = outbound*).
Du behältst das Urheberrecht an deinem Beitrag, erlaubst aber die Nutzung
unter MIT.

Kein Copy-Paste aus fremden Repos ohne Lizenz-Klärung. Wenn du Code
übernimmst, kennzeichne Quelle und Lizenz im PR.

## Code of Conduct

Respektvoller Umgang ist Pflicht. Siehe [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Was **nicht** ins Repo gehört

- `.env` mit echten Secrets
- Proprietäre Modelle, Modell-Gewichte, große Binärdateien
- Forks von Open-WebUI oder Ollama (das sind eigenständige Upstream-Projekte)
- Kundenspezifische Konfigurationen
