# Prompt-Bibliothek

Vorgefertigte Prompts für typische KMU-Aufgaben. Jeder Prompt ist eine
Markdown-Datei mit einem kurzen Erklärungsteil und dem eigentlichen
System-Prompt zum Kopieren.

## Integration in Open-WebUI

1. Settings → Personalization → Prompts → `+`
2. Name und Befehl setzen (z.B. `/angebot`)
3. System-Prompt aus der jeweiligen Datei kopieren
4. Speichern

Ab dann in jedem Chat mit `/<befehl>` aufrufbar.

## Beitragen

konkrete Aufgabe, deutsche Sprache, keine sensiblen Daten in Beispielen.
